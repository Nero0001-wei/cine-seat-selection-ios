Optional local screen video

The public repository does not include a movie trailer or film reference image.
The app builds and runs without media and displays a static blue screen.

To use a video you own or are permitted to redistribute:
1. Name it cinema-trailer.mp4 (also supports .mov or .m4v).
2. Place it in this directory.
3. Build and run the app again.

Playback is muted and loops only in an active seat preview.
The original aspect ratio is preserved.
Missing or invalid video keeps the static fallback.

Optional movie media is ignored by Git by default.
